# COSC4426Assignment-1
This project simulates a parabolic scientific phenomenon.  In this phenomenon, a bowler (the ball pitcher in a baseball game) is simulated to throw a ball randomly.  This project is built by Unity. The program uses the Unity’s physic features, first, the Rigidbody component is added on this ball, and a force is implemented on the ball, then the parabolic trail of the throwed ball movement is shown. In order to simulate the procedure more realistically, we add a bowler(character) with related animations, idle and pitching, and set the event that bowler throws the ball when his right arm swings in high position, then create a ball instance and implement the force on the ball. That’s would make this ball physical movement more naturally.
